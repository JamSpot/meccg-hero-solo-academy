# MECCG Hero Solo Academy

A structured solo-learning system for the Middle-earth: The Wizards CCG, built around Hero play.

## Academy baseline
- Hero only
- Gandalf as the Academy Wizard
- Primary card pool: The Wizards + The Dragons
- Genuine physical cards only; no proxies
- Historical Dwarven Quest / Pallando Challenge Deck strategy as the learning baseline
- Dragon content is environmental/advanced rather than Dragon-heavy beginner play

## Core learning loop
Prepare → Travel → Marshal → Grow Stronger → Travel Further → Recover → Repeat

The companion website is in `site/` and is deployed with GitHub Pages.
