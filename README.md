# MECCG Hero Solo Academy

A structured solo-learning system for the **conventional Hero-vs-Hazard game** in the Middle-earth: The Wizards CCG.

## Wizard choice review

The current one-Gandalf build is a working baseline. The [Wizard Choice Workshop](https://jamspot.github.io/meccg-hero-solo-academy/decks/wizard-choice-workshop/) compares Gandalf and Pallando, the three-avatar deck limit, the one-avatar-in-play rule, and legal 37- and 38-card variants.

## Academy baseline
- Conventional Hero solo play: one player controls one or more Hero companies against a separate Hazard deck; the first lesson uses one company.
- Current working first-play Hero play deck: 36 cards (30 Resources, five non-Wizard characters and one Gandalf); separate 30-card Hazard deck and 15-card Location deck.
- Hero only.
- Gandalf as the Academy Wizard.
- Primary card pool: The Wizards + The Dragons.
- Genuine physical cards only; no proxies.
- Historical Dwarven Quest / Pallando Challenge Deck C strategy as the learning baseline.
- Dragon content is environmental/advanced rather than Dragon-heavy beginner play.

## What this project is not
This repository is **not** the Arda format project. Its active 36-card Gandalf-led Hero play deck, separate 30-card Hazard deck, Rivendell-to-Moria first expedition and conventional solo procedure are not Arda rules or Arda pile lists. The historical Challenge Deck C reference had 38 Resource/character cards; the current Academy working build uses a 36-card Gandalf adaptation rather than preserving the original Pallando package.

Arda card pools, Arda rules and Arda-specific solitaire variants are maintained in a separate project and are intentionally outside this repository's scope.
