# Hazard Legality Workshop — sort the hand before playing

This is a table exercise using the Academy's fixed Dwarven Quest / Pallando Challenge Deck C Hazard list. It connects three decisions that must stay separate:

1. **Route:** what site path did the company declare?
2. **Legality:** which cards can be played against that path, site and company?
3. **Opposition:** which legal combination is most disadvantageous within the Hazard Limit?

Use physical cards and check their current wording. The card database and official rules may include errata that differs from an old printed card.

## The fixed situation

You control the five-character starting Dwarf company from Challenge Deck C: Thorin II, Dori, Kíli, Glóin and Óin. None is a Hobbit or an Orc scout, so this company's base Hazard Limit is **5**.

The company has declared movement from **Rivendell to Moria** using Region Movement. Moria has been revealed. You declare the legal site path:

**Rhudaur → Hollin → Redhorn Gate**

Before using this example in a real game, verify the region adjacency on your physical Region cards. This path contains three Wilderness regions, and Redhorn Gate is the named region containing Moria.

Under the Academy's selected solitaire procedure, Moria's normal Hazard draw number of 3 produces a draw of **2 + (2 × 3) = 8 cards**. The Hazard Limit remains five; drawing eight does not allow eight ordinary Hazard plays.

The eight cards below form a **constructed practice hand**, not a claim about what a random draw will produce:

- Cave Worm ×2
- Giant Spiders
- Lesser Spiders
- Neeker-breekers
- Watcher in the Water
- Full of Froth and Rage
- Wake of War

Assume neither support event is already in play and that no other card changes the route, attacks or Hazard Limit.

## Your task — do this before opening the answer key

For each card, write down:

- the exact key or condition that would make it legal;
- whether that key/condition is satisfied here;
- whether the card is a creature, short-event, long-event or permanent-event;
- how it would affect this company;
- whether it consumes one Hazard Limit slot;
- whether its effect can change or disappear before a later attack resolves.

Then choose the five-card combination that creates the greatest disadvantage for this company. You may not exceed the limit, invent a key, or ignore timing. If an attack is defeated and that causes a support event to be discarded, account for that before resolving the next attack.
