# Corruption Check Lab — Choose the Book Bearer

**Purpose:** learn to read corruption-check modifiers correctly, choose a Book of Mazarbul bearer, and run the Hazard side honestly.

This lab corrects a common but costly misunderstanding: a **+1 corruption-check modifier helps** because it is added to the 2D6 roll; a **-1 modifier hurts** because it lowers the roll.

## Rules you must apply

1. Roll 2D6 and apply the character's corruption-check modifiers.
2. Add +1 for each other character in the same company tapped to support the check.
3. Compare the modified roll with the bearer's total corruption points.
4. The check succeeds only when the modified roll is **greater** than the total corruption points.
5. A Hero who rolls equal to the CP total or one below is discarded; two or more below is eliminated. If the character is a Wizard avatar, a failed check ends the game.
6. Count every corruption point on every card the bearer controls, not just Book of Mazarbul.

## The bearer candidates

Assume the Book is the only card giving corruption points. It gives **2 CP**.

| Candidate | Printed check modifier | Other relevant fact |
|---|---:|---|
| Gandalf | +1 | Wizard; Sage; Despair of the Heart cannot target him. |
| Thorin II | 0 | No printed check modifier. |
| Glóin | 0 | No printed check modifier; body 9. |
| Dori | -1 | The modifier is a penalty. |
| Kíli | -1 | Scout skill is useful, but the modifier is a penalty. |
| Óin | -1 | Ranger skill is useful, but the modifier is a penalty. |

## Your tasks

1. Which character is the safest bearer if Gandalf is in the company?
2. With Gandalf carrying only the Book, what is the lowest possible modified roll? Does he need a helper?
3. If Gandalf is absent, which starting Dwarves avoid a negative corruption modifier?
4. How many helpers does a zero-modifier Dwarf need to guarantee success with only the Book's 2 CP?
5. How many helpers does Kíli need to guarantee success with only the Book?
6. Why is Kíli not automatically the best bearer just because he is a Scout?
7. Can the Hazard player play Despair of the Heart on Gandalf?
8. If Kíli carries the Book and Despair of the Heart is played on him, what is his new CP total and what happens when anyone in his company is wounded?
9. What is the tactical cost of tapping helpers during the Organization Phase if the company intends to move that turn?
10. If Gandalf carries the Book, how can he use its Sage-only ability?
