# Site-Keying Workshop — read the symbols, not the theme

This short table exercise fixes an easy-to-make but important mistake: **a region type and a site type are not the same thing**. A Hazard may still be legal, but you must identify the correct reason.

Use the physical Challenge Deck C cards. If an old printed wording differs from the current card database or a ruling, stop and verify before playing.

## The fixed journey

Your five-Dwarf company moves from **Rivendell to Moria** using Region Movement:

**Rhudaur → Hollin → Redhorn Gate**

All three Region cards show Wilderness [{w}]. The route has three regions, includes both endpoints, and names Redhorn Gate.

Moria's Hero site card gives these facts:

- Region: **Redhorn Gate**
- Site type: **Shadow-hold [{S}]**
- Site path: **two Wilderness [{w}{w}]**
- Nearest Haven: **Lórien**
- Automatic attack: **Orcs — four strikes with 7 prowess**

**Moria is not a Ruins & Lairs [{R}] site.** This distinction is the point of the exercise.

## Read the symbols

| Symbol | What it means | It is not |
|---|---|---|
| Lowercase **{w}** | Wilderness region type | A site type |
| Lowercase **{s}** | Shadow-land region type | Shadow-hold |
| Uppercase **{R}** | Ruins & Lairs site type | Redhorn Gate |
| Uppercase **{S}** | Shadow-hold site type | Shadow-land |
| Uppercase **{D}** | Dark-hold site type | Dark-domain |

The letter may look similar, but its case changes the meaning. Always check the Region card or Site card itself.

## Your task — classify each Hazard

For each card, write down the exact route or site key that makes it legal here. Do not just write “it fits Moria”.

| Hazard | Printed key or special wording to check | Which part of this journey satisfies it? |
|---|---|---|
| Cave Worm | Named-region key | |
| Giant Spiders | Double-region key and special site keys | |
| Lesser Spiders | Region-type keys and {R} site key | |
| Neeker-breekers | Region-type keys and {R} site key | |
| Wargs | Region-type keys | |
| Watcher in the Water | Double-region key and explicit Moria wording | |

Then answer:

1. Is Lesser Spiders legal here? If yes, is it because Moria is a Ruins & Lairs site?
2. Is Neeker-breekers legal here? If yes, which key makes it legal?
3. Can Giant Spiders use a special Shadow-hold site key at Moria, or is the route's double-Wilderness key the relevant one?
4. Why can Watcher in the Water be played at Moria even though the Moria site type does not match a Ruins & Lairs key?
5. Does Cave Worm prove that Region Movement exposes an extra named region in this example?

## Bonus comparison — Starter Movement from Lórien

Moria lists Lórien as its nearest Haven. If the company is at Lórien and uses Starter Movement to Moria, Moria's printed site path supplies two Wilderness regions, and the origin and destination region names are used as specified by the Starter Movement rules.

Cave Worm is still worth checking because **Redhorn Gate is the destination region**. It is not a special extra key created only by Region Movement. The direct Rivendell → Moria Region Movement path additionally names Hollin, but none of the fixed Challenge Deck C creatures in this exercise is keyed specifically to Hollin.

This is why you must separate:
- the movement route;
- the site path and its region types;
- the named regions available for named-region keys;
- the destination site's actual site type and any explicit site-name wording.

## Fair-play rule

Do not reject a legal Hazard because you have misread its key. Do not make an illegal Hazard legal because the company looks too strong. Record the precise reason for every decision, then apply the solo rule to choose the most disadvantageous legal combination within the Hazard Limit.
