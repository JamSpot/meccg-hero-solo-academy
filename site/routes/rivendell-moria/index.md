# Rivendell → Moria

**Campaign:** Historical Dwarven Quest  
**Objective:** Acquire the Book of Mazarbul  
**Start:** Rivendell  
**Destination:** Moria  
**Movement:** Region Movement  
**Example site path:** Rhudaur → Hollin → Redhorn Gate  
**Exposure:** Named regions affect which Hazards are legal.  
**Site personality:** Objective / Resource acquisition  
**Reward:** Book of Mazarbul  
**Follow-up:** Blue Mountain Dwarf-hold

## Lesson

A route has at least four distinct values: legality, exposure, destination reward and future position.
