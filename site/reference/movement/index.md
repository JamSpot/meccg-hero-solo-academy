# Movement & Route Planning

Use **player-directed movement** as the teaching term.

## Keep these separate

**MOVEMENT ROUTE ≠ SITE PATH ≠ HAZARD EXPOSURE**

- **Movement Route:** the legal movement chosen during Organization.
- **Site Path:** the declared path used for Hazard keying.
- **Hazard Exposure:** what the chosen path makes legal for the Hazard player.

## Route planning order

**LEGALITY → DESTINATION → EXPOSURE → RISK → VALUE → POSITION**

## Four questions

1. **WHERE?** What is the destination?
2. **HOW?** What movement type makes the trip legal?
3. **WHAT?** What does the route expose?
4. **THEN?** Where does the company finish, and what does that enable?

The map is not the site path. A route is not merely distance between sites; it is also Hazard exposure and future position.


## Beginner route-planning drills

Before Game 2, practise these physically with the Region cards:

1. **Four means four:** build A → B → C → D and count the origin and destination.
2. **Five is illegal:** A → B → C → D → E exceeds the normal Region Movement limit.
3. **No repeats:** A → B → C → B → D is illegal.
4. **Starter vs Region:** compare the simpler Starter route with the greater control and exposure of Region Movement.
5. **Same destination:** compare two legal routes by Hazard exposure, arrival condition and future position.
6. **Arrive vs enter:** reaching a site does not force the company to enter it.
7. **Recovery:** a damaged company should compare pressing on against recovering and redeploying.

### Game 1 movement script

Say the decisions aloud in order:

> **Destination: Moria.**
>
> **Movement type: Region Movement.**
>
> **Route: Rhudaur → Hollin → Redhorn Gate.**
>
> **Three regions, no repeated region.**
>
> **Declared site path identified.**
>
> **Now assess Hazard exposure before resolving the Hazard step.**

The Academy goal is not to memorise one route. It is to learn the repeatable process:

**DESTINATION → MOVEMENT TYPE → LEGALITY → COUNT → SITE PATH → EXPOSURE → ARRIVAL → ENTRY → NEXT POSITION**

### Captain's rule

> **Don't ask only “Can I get there?” Ask: “What does getting there do to the whole expedition?”**
