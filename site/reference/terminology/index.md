# Academy Terminology

- **Tempo:** Progress − Recovery.
- **Expedition:** A purposeful sequence of movement, site activity and recovery.
- **Critical Character:** The character whose disruption creates the greatest expedition damage.
- **Position Value:** Strategic value of where a company finishes a turn.
- **Movement Debt:** Hidden strategic cost created by unnecessary movement.
- **Opportunity Density:** How many useful options a route creates over the next expeditions.
- **Expedition Compression:** Making one expedition accomplish multiple useful jobs.
- **Stored Value:** Strategic value retained by keeping a card unplayed.
- **Strategic Elasticity:** Maintaining a primary objective, secondary objective, safe retreat and productive alternative.
- **Expedition Abort:** Deliberately postponing or abandoning an objective when remaining cost no longer justifies expected value.
- **Hazard Pressure Budget:** The Hazard player's cards, Hazard Limit, information and timing.
- **Objective Transformation:** The moment an acquired objective changes into a delivery, security or follow-up problem.
- **Recovery Site:** A site whose strategic purpose is restoring expedition capability.
