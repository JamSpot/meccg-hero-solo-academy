# Free / Player-Directed Movement

The Academy uses “free movement” as a beginner-friendly phrase. The formal rules term is **Region Movement**.

It does not mean unrestricted movement.

## The movement algorithm

**DESTINATION → MOVEMENT TYPE → LEGALITY → ROUTE → SITE PATH → EXPOSURE → REWARD → NEXT POSITION**

Keep these separate:

- **Movement route:** where the company travels.
- **Site path:** the region types used for creature-Hazard keying.
- **Hazard exposure:** what the route makes legal for the Hazard player.

## Core rules

- Normal Region Movement allows up to four regions.
- The origin and destination regions count.
- A region cannot be repeated during the movement.
- Player route control gives more choice, but can also increase Hazard exposure.

## Captain's route test

Before moving, say:

> I am going to ______ because ______.

Then:

> I am travelling through ______ because ______.

Then:

> When I arrive, I want to ______.

If the last answer is unclear, reconsider the expedition.
