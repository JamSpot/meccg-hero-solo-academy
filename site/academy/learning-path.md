# Academy Learning Path

Follow these lessons **in order**. Each lesson has one main job. Finish it, then use its “Next” link to move forward. The All Pages directory is a reference index, not the course sequence.

## After the core course

Only after you can run the core expedition loop comfortably, continue to:

1. **Combat and avoidance** — choose when to fight and when to preserve the company.
2. **Recruitment and influence** — improve the company deliberately.
3. **Expedition compression** — combine useful goals when the route and risk justify it.
4. **Corruption and abort decisions** — recognise when to recover rather than press on.
5. **Campaign planning** — connect expeditions into a longer objective.
6. **Advanced card pools** — sideboarding, specialised Hazard packages and optional Dragons.

Use the [Games and Lessons index]({{ '/games/' | relative_url }}) for the later sequence, or [All Pages]({{ '/navigation/' | relative_url }}) only when looking up a specific topic.

## The lesson pattern

**DO → STOP → DECIDE → EXPLAIN → CONTINUE → DEBRIEF**

Every lesson should tell you what to accomplish, what cards you need, what to do physically, where to stop and decide, which rule explains the choice, and what to practise next.

> **Course rule:** do not introduce a new system merely because it exists. Introduce it when it solves a problem you have already encountered at the table.
