# Academy Learning Path

The Academy is a course. You should be able to sit down with the cards and always know what to do next.

## The lesson pattern

**DO → STOP → DECIDE → EXPLAIN → CONTINUE → DEBRIEF**

Every lesson should tell you:
1. what you are trying to accomplish;
2. what cards you need;
3. what to do physically;
4. where to stop and make a decision;
5. which rule explains that decision;
6. what to practise next.

## Course order

### 0. Set up
Build the exact teaching Hero and Hazard decks and lay out the table.

### 1. First Expedition
Play Game 1: **Rivendell → Moria → Book of Mazarbul**.

Learn the basic expedition loop without trying to master every rule.

### 2. Free / Player-Directed Movement
Learn Region Movement and why route choice affects Hazard exposure.

### 3. Route Planning
Compare routes by legality, exposure, reward, arrival condition and future position.

### 4. Hazard Player
Learn:
**LEGALITY → TARGET → DISRUPTION → SEQUENCING → PRESSURE**

### 5. Site Decisions
Learn arrival, entry, automatic attacks and objective attempts.

### 6. Recovery
Learn when to press on and when to return.

### 7. Combat
Only now make combat a dedicated lesson.

### 8. Recruitment and Influence
Build the company deliberately rather than adding characters randomly.

### 9. Compression
Make one expedition accomplish several useful jobs.

### 10. Corruption and Abort
Learn the long-term cost of greed and how to leave before an expedition collapses.

### 11. Campaign Play
Plan several expeditions rather than isolated turns.

### 12. Advanced Card Pools
Add sideboarding, Dragons and more specialised strategies only after the core loop is comfortable.

## The rule

Do not introduce a new system merely because it exists.

Introduce it when it solves a problem the player has already encountered at the table.
